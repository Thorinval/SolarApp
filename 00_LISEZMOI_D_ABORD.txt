🚀 COMMENCER EN 4 ÉTAPES

1️⃣  CONFIGURER VOS CREDENTIALS ATMOCE

   cd D:\AtmoceSolarApp
   dotnet user-secrets init
   dotnet user-secrets set "Atmoce:BaseUrl" "https://YOUR_URL/openapi/v1"
   dotnet user-secrets set "Atmoce:ApiKey" "YOUR_API_KEY"
   dotnet user-secrets set "Atmoce:ApiSecret" "YOUR_API_SECRET"

2️⃣  CRÉER LA BASE DE DONNÉES

   dotnet ef database update

3️⃣  LANCER L'APPLICATION

   dotnet run

4️⃣  ACCÉDER À L'APPLICATION

   Ouvrez votre navigateur : https://localhost:7000

🔧 TECHNOLOGIE UTILISÉE

Framework       : Blazor Server (.NET 9.0)
Base de données : SQL Server (LocalDB, Express ou distant)
ORM             : Entity Framework Core 9.0
Client API      : HttpClient avec Newtonsoft.Json
Interface       : Bootstrap 5 + Razor Components

📂 STRUCTURE DU PROJET

Models/
├── AtmoceDtos.cs         ← Modèles de l'API Atmoce
└── DomainModels.cs       ← Entités de la base de données

Services/
├── AtmocApiService.cs    ← Client API Atmoce avec authentification
└── SolarDataService.cs   ← Logique métier (synchronisation, requêtes)

Data/
├── AtmocDbContext.cs     ← Configuration Entity Framework
└── Migrations/           ← Migrations de base de données

Components/Pages/
├── Home.razor            ← Dashboard principal
├── Sync.razor            ← Page de synchronisation
└── SiteDetail.razor      ← Détails d'un site

🔐 SÉCURITÉ

✓ Authentification API Atmoce avec tokens Bearer
✓ Refresh automatique des tokens (validité 30 jours)
✓ User Secrets pour stocker les credentials de façon sécurisée
✓ HTTPS activé par défaut
✓ Configuration externalisée (pas de secrets dans le code)

En production, utilisez Azure Key Vault ou AWS Secrets Manager.

📞 EN CAS DE PROBLÈME

1. Vérifier que SQL Server LocalDB est installé
   → Vérifier dans Visual Studio ou via SqlLocalDB

2. Vérifier les credentials Atmoce
   → dotnet user-secrets list

3. Consulter les logs en console
   → Rechercher [Error] ou [Warning]

4. Lire la documentation
   → README.md ou INSTALL.md

5. Réinitialiser la base de données
   → dotnet ef database drop
   → dotnet ef database update
