🚀 DÉMARRAGE RAPIDE

1. Configurer les credentials Atmoce:
   ────────────────────────────────────
   cd D:\AtmoceSolarApp
   dotnet user-secrets init
   dotnet user-secrets set "Atmoce:BaseUrl" "https://YOUR_URL/openapi/v1"
   dotnet user-secrets set "Atmoce:ApiKey" "YOUR_API_KEY"
   dotnet user-secrets set "Atmoce:ApiSecret" "YOUR_API_SECRET"

2. Créer la base de données:
   ──────────────────────────
   dotnet ef database update

3. Lancer l'application:
   ─────────────────────
   dotnet run

4. Accédez à:
   ──────────
   https://localhost:7000

5. Synchroniser les données:
   ──────────────────────────
   Aller à https://localhost:7000/sync
   Cliquer sur "Démarrer la synchronisation"
